## Área de Login/Cadastro

### Instrução de tela Login

- CRIE APENAS ARQUIVOS (Não crie pastas):
    -HTML
    -CSS 

- Fundo cinza mediano
- Letra branca 
- **Card** centralizado com opções centralizadas com fundo cinza escuro:
    - Título escrito "Entrar na conta"
    - 2 Campos de input sem escrito do lado
        - Login: placeholder " Nome de usuário ou E-mail " centralizado: Esse campo deve aceitar nome de usuário ou e-mail para logar
        - Senha: placeholder " senha " centralizado

- **2 Botões** centralizados com escrito centralizado e um ao lado do outro com mesma cor do card, um pouco menores proporcionalmente que o card e com botton:
    - Botão 1 com escrito "Continuar" centralizado:  e que continua para o site já com usuario logado, deixe esse botão com area de link pronto para o link da pagina com o usuario logado.
    - Botão 2 com escrito "Criar novo usuário" centralizado: e que continua para o site de cadastro.


### Instrução de tela Cadastro

- Faça a mesma estrutura do "Instrução de tela Login"
- Título escrito "Cadatrar Usuário"
- Acrescente mais 3 campos de input(os dois primeiros de 5 campos ficarão na primeira linha):

    - Nome de usuário ou E-mail
    - Data de nascimento
    - E-mail
    - Senha
    - Confirmar senha

- 2 botões:
    - Botão 1 com escrito "Continuar" centralizado: e que continua para o site já com usuario logado, deixe esse botão com area de link pronto para o link da pagina com o usuario logado.
    - Botão 2 com escrito "Já tenho uma conta?" centralizado: e que continua para a tela de login.
