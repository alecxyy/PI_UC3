# Página de perfil e página de planos
- sao duas páginas de um site 


## REGRAS ##
- utilizar apenas CSS e HTML
- **NÂO UTILIZAR** javascript
- **NÂO NOMEAR** arquivos com "INDEX e INÍCIO", optando por PERFIL.HTML e PLANOS.HTML
- Apenas um arquivo CSS para as duas páginas
- Utilizar imagens placeholder
- fazer o CSS baseado nas imagens anexadas
- paleta de cores baseadas tambem nas imagens

## Página de perfil ##
- Há um banner junto com a foto de perfil para mostrar o usuario
- Abaixo da foto de perfil há uma opção para uma seleção de títulos que aparece como um pop-up para que o usuario possa selecionar qual dos títulos ele quer exibir em seu perfil
- No canto superior direito há uma engrenagem feita para editar a foto de perfil e o banner
- Abaixo do titulo há duas imagens com a quantidade de curtidas no perfil e a quantidade de seguidores
- no lado inferior direito da área do usuario há um espaço para uma breve descrição do usuario
- Não coloque o campo de comentários exibido nas imagens, apenas as informações de curtidas e seguidores
- Botão "Planos" acima da foto de perfil, que some se ele for assinado
- se o plano for assinado, a foto de perfil ganha estrelas em volta.

## Página de planos ##

- h1 escrito "Planos"
- 3 cards com 3 planos:
- 1°: h1 escrito "Grátis" (opção padrão)
- 2°: h1 escrito "Básico" preço mensal 20,00 reais 
- 3°: h1 escrito "Premium" preço mensal 30,00 reais
- Botão "Voltar" no canto superior esquerdo
- cada card tem informações do plano e um botão para contratar
- Estrelas em volta do card "Premium"

## Pop-up com títulos ##
- O pop-up é uma seleção de títulos, feito para o usuario escolher qual título ele quer exibir em seu perfil
- Há cerca de 20 opções de títulos (placeholder)
- é um pop up pequeno, centralizado na página 
- há um slider feito para vizualisar todos os títulos
- Ao clicar em qualquer titulo, o titulo é adicionado ao perfil do usuario
- o pop up some ao clicar em qualquer lugar fora dele
- há uma barra de pesquisa para que seja possivel pesquisar por títulos
